# DineDesk
# 🍽️ DineDesk

A modern Restaurant Table Booking and Online Food Ordering Platform that enables customers to reserve tables, browse digital menus, place online food orders, and track their orders in real time. The platform provides dedicated interfaces for customers, restaurant staff, and administrators to ensure a seamless restaurant management experience.

---

## 📌 Project Overview

DineDesk is designed to digitize restaurant operations by allowing customers to book tables online, explore interactive digital menus, place food orders, and receive real-time updates. The platform also provides management tools for restaurant staff and administrators to handle bookings, menus, and customer orders efficiently.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/DineDesk.git
```

### Navigate to the project folder

```bash
cd DineDesk
```

### Install dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root.

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

### Run the project

```bash
npm run dev
```

The application will start on:

```
http://localhost:8080
```
